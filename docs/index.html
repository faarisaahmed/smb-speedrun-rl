Reinforcement learning · NES Super Mario Bros. (1985)

An AI that taught itself to speedrun Super Mario Bros.

A neural network playing the real cartridge in an emulator, starting from random button presses. No human demonstrations, no scripted tricks, small Mario only. After 2.4 billion steps of practice it clears every outdoor level, finds the speedrunners' shortcuts, and races the world's best tool-assisted runs.

03 · Head to head

Racing the tool-assisted runs, fairly

For a fair race the agent loads the TAS's own saved game at each level's start (the same power-up, the same enemies, the same frame-rule timing) and both are clocked to the moment the next level becomes playable, fireworks and castle walk included. Its fastest of 50 attempts counts.

05 · The story

What went wrong, and what fixed it

Most of the work was finding out why the agent was stuck. A rule held throughout: never script the answer. Each fix changes what the agent can see, how it's rewarded or where it practices, then lets it find the move itself.

    06 · Method

    How it works

    Sees memory, not pixels

    Each step, the visible screen is read from the console's RAM as a 13×17 grid of terrain tiles, enemies, platforms and items, plus Mario's exact position, speed and state, for this step and the last. A small dense network learns from that quickly on a CPU.

    Presses real buttons

    Twelve button combinations, chosen every 2 frames. Running is never forced and no technique is built in: it learned to hold B, time jumps, and stomp or dodge enemies on its own. It's told which buttons it's still holding, because a held A can't jump again.

    Rewarded for speed

    Pixels of progress (on the furthest point reached, so pipe shortcuts aren't punished), a small cost for every frame, a penalty for dying or stalling, and a bonus at the flagpole. That's all it's told.

    PPO with self-imitation

    Proximal Policy Optimization over 16 emulators at once. After each update, a few extra gradient steps make it more likely to repeat its own best runs and the explorer's discoveries.

    Go-Explore restarts

    Save states every 64 pixels it reaches. Half of all attempts restart from one, weighted toward spots where it keeps failing, so hard sections get practiced instead of replayed from the start. A curiosity bonus pays for entering a new area, fading with visits.

    Shown where, never how

    Late in training it got a few hints: practice starts placed just before the shortcuts the tool-assisted run takes, as small Mario, but none of the TAS's inputs. Finding the actual move is still up to it.
